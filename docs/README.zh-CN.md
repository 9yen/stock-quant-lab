# 股票日内模拟交易实验室

[English](../README.md) | 简体中文

这是学习用的模拟交易项目。仓库不含密钥、账户绑定、成交记录、运行状态或已启用配置；克隆代码不会自动启动交易。下文部分运行说明描述已配置的本机版本。

本项目把 Alpaca Paper 与 moomoo 模拟盘接到同一个本地网页，用分钟行情运行股票日内多空策略，查看持仓、成交、盈亏及每日复盘。moomoo 另有受限制的买入期权模块。

**仅用于模拟交易，不支持通过本项目切换真实资金。策略可能亏损，自动优化不保证提高收益。**

项目位置：`C:\path\to\stock-quant-lab`。本说明按 2026-10-17 的实现整理；旧文档中的 SPY 日线、六只股票、5% 仓位等属于早期版本。

## 平时怎么看

先打开本地网页：

- Alpaca：<http://127.0.0.1:8766/>
- moomoo：<http://127.0.0.1:8766/moomoo.html>

网页只在这台电脑上开放。关闭网页不会停止后台；电脑关机、休眠或网络中断会影响运行。已配置 Windows 登录后自动启动本地守护程序；守护程序每 20 秒检查并恢复退出的后台。电脑仍需保持唤醒并联网，moomoo 还需要 OpenD 登录。未登录 Windows 时不保证启动。

先检查账户更新时间、后台状态、行情时间和交易模式，再看盈亏。网页还在刷新，不代表交易程序一定运行。

| 提示 | 含义与处理 |
| --- | --- |
| 本场已结束 · 已空仓 | Alpaca 已正常结束；连续自动模式会等待下一官方交易日，旧场次不会重复启动 |
| 后台交易进程未运行 | 未能确认正常结束；检查日志和账户，不要反复启动多个交易程序 |
| 心跳过期 | 程序可能卡住；网页保留的数据不能当成实时结果 |
| 等待常规交易时段 | moomoo 正在待机，按官方交易日历等待开盘 |
| 行情或账户连接失败 | 暂停依赖旧数据作判断，先检查网络、API 或 OpenD |

两家均已按用户授权启用**连续模拟自动交易**。Alpaca 按官方交易日历自动管理每日场次，最早开盘前 15 分钟准备当天授权；确认旧场次空仓、订单核清、账户匹配后才续到新一天。moomoo 在非交易时段持续待机。手动停止开关和当日风控锁定不会被守护程序清除。

## 当前交易规则

两家券商资金、订单、持仓、停止开关及盈亏记录独立。

| 规则 | Alpaca | moomoo |
| --- | --- | --- |
| 股票观察池 | 100 只自选股票，另保留 SPY/QQQ/IWM 的退出处理 | 100 只自选股票 |
| 行情与方向 | 1 分钟，多空双向；做空还受券商可借券限制 | 1 分钟，多空双向；以模拟账户可交易权限为准 |
| 新仓目标 | 账户净值的 10% | 账户净值的 10% |
| 单只硬上限 / 组合总敞口 | 40% / 100% | 40% / 100% |
| 同时占用名额 | 最多 10 只，包含未成交入场预留 | 最多 10 只，包含未成交入场预留 |
| 每日入场次数 | 每只 19 次、总共 100 次 | 每只 19 次、总共 100 次，含期权入场 |
| 同股入场冷却 | 15 分钟 | 5 分钟 |
| 股票固定止损 / 止盈 | 1% / 2% | 1% / 2% |
| 策略每日亏损预算 | 本场基准净值的 1% | 当日基准净值的 2% |

40% 是硬上限，不是每次自动分配 40%。组合多空敞口按绝对值相加，不以多空抵消。Alpaca 另保留早期约定的 20% 绝对容忍上限，策略会先按 1% 预算停止新增入场并尝试退出。

入场采用开盘区间突破，结合 MA20 方向、VWAP、成交量过滤，基准开盘区间不超过 3%、突破距离不超过 1.5 倍 ATR14。不是每分钟必须成交，也不会因为一笔出现浮盈就立即卖出。退出依据止盈、止损、风险锁定及收盘时间；退出不应被入场次数限制阻止。

常规收盘前 30 分钟停止新开仓，前 10 分钟开始撤单平仓。实际交易时间由券商日历确定，包含半日市；新西兰与美国夏令时变化会改变本地开盘时间。

## moomoo 期权

期权权限需要按每个本地模拟账户独立验证，仓库不附带任何账户权限。已配置版本支持受限的买方模块。只买 Call/Put，不卖裸期权；选择 7–21 天到期的标准合约，**不是末日期权策略**。

- 每次 1 张，同时最多 2 笔，每天最多 8 次期权入场。
- 单笔权利金不超过净值的 0.25%，且不超过 2,500 美元；同时受现金和组合总敞口限制。
- 检查价差、报价时效、成交量和持仓量；不满足条件就跳过。
- 权利金止损 25%、止盈 40%，持仓 30 分钟退出，并受每日风险及收盘退出规则约束。

Alpaca 期权当前没有接入自动执行。老虎 API 因账户条件未满足，暂未启用。

**moomoo 的止盈止损由本机程序检查，不是券商托管的保护单。电脑、OpenD 或网络离线时无法保证及时退出。** Alpaca 使用券商保护单的路径仍需检查订单是否实际生效。

## K 线与盈亏怎么看

股票下拉框支持输入搜索；可调整均线周期，查看分钟量及成交标记，缩放后拖动查看历史。

- 买入·开多 → 卖出·平多：多头完整交易。
- 卖出·开空 → 买入·回补：空头完整交易；回补就是空头退出。
- 浮动盈亏：还持有的仓位随价格变化的结果。
- 已实现毛利：已平仓部分的盈亏，按成交记录 FIFO 配对计算。
- 已平仓收益率：平仓收益相对于配对入场金额；不同于整个账户当日收益率。
- 历史复盘：按美东交易日查看，包括已清空的股票及表现最好、最差的股票。

Alpaca 页面用 moomoo NZ 美股费用模型估算净收益，**并非 Alpaca 实际扣费**。模型包括平台、交收及适用监管费用，费率实现在 `quant_lab/review.py`，实际券商收费表可能变化。

moomoo 模拟接口目前未提供可用于精确对账的订单费用，因此策略复盘显示毛收益，账户净值变动单独展示；不要把毛利当成精确扣费后收益。此前手动持仓清理记录与策略业绩分开。

## 每日自动复盘与优化

已建立本地每日任务：奥克兰时间周二至周六 10:30。电脑需唤醒、Codex 需运行；行情归档还需要 OpenD 和扫描器在线。

查看 moomoo 网页的“自动优化”。至少积累 30 个有效行情日和 100 笔实际股票平仓订单后，才进行受限参数比较。训练、验证、留出分开，计入费用与滑点压力；通过门槛且空仓、订单核清后，才允许下一交易日换版。

只允许在预设的量比、区间宽度、突破距离组合中调整股票入场过滤，不自动改源码、仓位、止损、交易权限。Alpaca 与期权目前仅复盘，不自动改参数。详见 [自动优化说明](../AUTO_OPTIMIZATION.md)。

## 启动与停止

以下操作在项目文件夹内执行。日常优先使用统一守护入口 `start_automatic.cmd`；已有守护程序会通过文件锁拒绝重复实例。无需逐一启动券商进程。网页顶部两张相同样式的状态卡显示两边的启用状态、等待原因和最近更新时间。

守护程序只自动重启已经退出的后台；不会强杀仍存活但心跳过期的交易进程，以免未知订单重复提交。状态过期、隔夜持仓或订单不一致会显示需要检查。它不是云端服务，无法在本机关机期间执行。

下面的单进程命令用于排查，正常使用不需要逐一运行。

### 网页服务

```powershell
cd C:\path\to\stock-quant-lab
.\.venv\Scripts\python.exe web_dashboard.py
```

保留终端运行；打开上述本地网址。网页服务只展示状态，不会顺带启动交易执行器。

### moomoo

先登录 OpenD，确认本机端口 `11111` 可用。分别在独立终端运行以下进程，各自保留窗口：

```powershell
.\.venv-brokers\Scripts\python.exe moomoo_observer.py --watch
.\.venv-brokers\Scripts\python.exe moomoo_market.py
.\.venv-brokers\Scripts\python.exe moomoo_options_watch.py
.\.venv-brokers\Scripts\python.exe moomoo_auto.py --execute-paper
```

最后一条会启动已配置的**模拟自动下单**，不是预览。需先确认模拟模式、配置、持仓归属及无重复执行器。网页的停止按钮会设置 `STOP_MOOMOO`，执行器会尝试撤单并退出自身管理的仓位；必须查看订单及持仓确认完成。停止标记保持有效，重新启用前应先核查状态，不能仅靠重复启动恢复。

### Alpaca

正常使用由 `alpaca_auto.py --execute-paper` 自动管理，无需每天手动改日期。它复用既有策略与仓位参数，仅更新通过核对的交易日；不清除当日次数、风险状态或订单账本。

`start_paper.cmd` 固定了旧日期 `2026-10-16`，仅为历史快捷方式，不用于自动模式。底层 `paper_intraday.py` 仍是单场执行器，由自动管理器传入当天美东日期。日历或账户查询失败时不会盲目续期，前一天未核清的订单、隔夜持仓会阻止新场次。

Alpaca 网页停止按钮设置独立的 `STOP_PAPER`。停止请求不等于立即成交，仍要核查持仓、挂单与日志。

## 常见排查

1. 网页打不开：先检查网页服务是否运行，端口是否为 8766。
2. 网页能看但不成交：检查交易时段、执行器心跳、停止开关、当日风险锁定、行情时效、次数和入场条件。
3. moomoo 数据停住：检查 OpenD 已登录、端口 11111、行情权限及扫描器；网页缓存可能仍能显示旧图。
4. 持仓有浮盈却没卖：核查退出条件和保护单；浮盈本身不是退出信号。
5. 收盘后 Alpaca 不运行：若显示自动等待下一场且空仓，属于正常状态；守护程序会按官方日历继续检查。若自动守护离线，运行 `start_automatic.cmd`，不要使用旧固定日期快捷方式。
6. 出现未知订单或账户持仓不一致：先停止新增交易、核对券商订单，不要删除账本或盲目重复提交。

开发检查：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

测试通过说明已覆盖的程序行为符合预期，不代表策略已被证明能稳定盈利。
