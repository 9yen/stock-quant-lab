# Security

Do not put credentials or private account data in public issues. If a credential is accidentally published, revoke it with its provider immediately; removing the visible file does not remove Git history.

The web service binds to loopback and rejects unexpected Host headers. Stop requests require the dashboard origin and token. It is not designed for public hosting or remote multi-user access.

Execution is restricted to Alpaca's exact paper endpoint and moomoo SIMULATE accounts. A fresh clone contains no enabled automation, account bindings or broker state. Do not change these restrictions to connect real funds.

Local stops require a running computer, gateway, network and broker response. Supervisor restarts do not guarantee exits during outages and never erase a manual stop or same-day risk lock.
